# Store listing: English (default language)

**App name (max 30):** LearnQuest Jungle Run
**Short description (max 80):** Run through the jungle, answer fun questions and learn while you play!

**Full description (max 4000):**

Run through a bright 3D jungle, collect coins, jump over rocks and answer story questions on the way. LearnQuest Jungle Run turns practice into an adventure for children in Grades 1 to 3.

WHY CHILDREN AND PARENTS LIKE IT
• Every question is a little jungle story: Monkey Maths, Treasure Gate, Banana Bridge, Parrot Post and more.
• Time to read: the runner stops at every question and waits until the child taps "Ready!". No clock, no pressure. A Listen button reads the question aloud.
• A friendly teacher runs behind you if you stumble. If you get caught, she explains what went wrong and gives you one more chance to answer.
• Maths, patterns, spelling, science and shapes. Pick the subjects and the class level in Settings.
• English, Hindi (हिन्दी) and Marathi (मराठी), switch any time.
• Boy or girl explorer, trails to unlock with the coins you collect, four jungle worlds (day, sunset, firefly night, misty dawn).
• Needs an internet connection to sign in and save progress.

SAFE BY DESIGN
• No ads. No in-app purchases. No tracking.
• A parent creates the account; children play through a profile. Parents can delete the child profile or the whole account any time.
• Your information is never sold or shared.
• Easy controls: swipe or tap to change lane, jump and slide.

PARENTS
Questions follow the school class level you choose. The parent dashboard shows progress and lets you set real-life tasks that earn coins. After a run the game shows which questions went right or wrong, so you can practise those again.

Made for curious children. Have fun learning!
